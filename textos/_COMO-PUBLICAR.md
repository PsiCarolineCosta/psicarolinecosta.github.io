# Como publicar um texto novo

1. Nesta pasta (`textos`), clique em **Add file → Create new file**.
2. Dê um nome terminado em `.md`, por exemplo: `2026-11-20-sobre-o-luto.md`
   (sem acentos e sem espaços — use hífens).
3. Cole o modelo abaixo e troque pelo seu texto:

```
---
titulo: Sobre o luto
data: 2026-11-20
resumo: Uma ou duas frases que aparecem no cartão do texto.
---
Primeiro parágrafo do texto.

Segundo parágrafo. Use *itálico* com um asterisco e **negrito** com dois.

> Para uma citação, comece a linha com o sinal de maior.
```

4. Clique em **Commit changes**. Em 1 a 2 minutos o texto aparece no site, em ordem de data (mais recente primeiro).

Para editar ou apagar um texto, abra o arquivo aqui e use o lápis (editar) ou os três pontinhos → Delete file.
